# Lunowa Design

This document is the textual source of truth for Lunowa's product and visual design.

## Status

Scaffold only. The detailed design specification will be added after the visual references are committed.

## Source-of-truth model

When design sources conflict, use this order unless a later decision explicitly supersedes it:

1. Current textual design specifications under `docs/design/`.
2. `references/00-brand-system.png` for brand identity and global visual language.
3. `references/01-component-system.png` for reusable component appearance and component states.
4. `references/02-desktop-conversation-default.png` for the canonical desktop shell and default layout.
5. State- or feature-specific visual references for the specific state or feature they demonstrate.

Visual references define appearance, hierarchy, density, relative sizing, and component placement. Markdown specifications define behavior, state transitions, exact rules, edge cases, accessibility, responsive behavior, and conflict resolution.
