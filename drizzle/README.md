# Production migrations

`migrations/` is the ordered production PostgreSQL migration set. The first
migration is owned by G10 and creates only the Better Auth application
identity/session schema proven by P14. The next migration is owned by G19 and
creates the provider-neutral evidence foundation against the production G10
`user.id` UUID target: ConnectedAccount, ProviderSyncState, Conversation,
Message, attachment metadata, ParticipantIdentity, and normalized message
participant edges. It does not create Gmail API behavior, Responsibility,
Temporal, Draft, or Send state.

The G19 migration is generated by Drizzle Kit `0.31.10` from the Drizzle ORM
`0.45.2` schema and is intended for PostgreSQL `18`. Its revision trigger is
the narrow PostgreSQL invariant that prevents a Conversation semantic
evidence revision from decreasing; the repository advances it using a
transactional row update.

Generate a migration after an authorized schema change with `pnpm db:generate`.
Production and CI apply the committed SQL; they do not use a schema `push`.
