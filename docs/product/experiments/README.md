# Product Experiments

This directory contains bounded, decision-relevant Product experiment plans when the experiment is complex enough that the repository needs a stable execution contract beyond a live GitHub Issue.

Rules:

- GitHub Issues own live execution state, participant/test evidence, and dispositions.
- `docs/product/PRODUCT.md` owns Product hypotheses and classification.
- Experiment plans here operationalize a bounded test; they do not promote hypotheses to accepted facts.
- Do not store raw private email, participant-identifying data, chat transcripts, or dated session dumps here.
- Supersede or remove stale plans when they would misroute implementation; Git history preserves prior versions.
