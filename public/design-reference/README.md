# Reference assets

`moment-assets.png` is an unchanged copy of the user-supplied
`docs/design/references/03-moment-conversation-reply.png` (1448 × 1086).
The reference preview clips only its logo and three sample portraits using CSS
background positions. The screen layout, text, controls, messages, backgrounds,
and borders are real HTML/CSS, not a screenshot overlay.

These sample assets are for the explicitly enabled local design preview. They do
not represent connected accounts or actual mailbox content. The existing live
application does not consume this fixture or adopt the reference's sample counts.
