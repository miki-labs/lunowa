# Google sign-in asset

`google-g.png` is the unmodified Google G asset from
https://developers.google.com/static/identity/images/g-logo.png, retrieved 2026-09-18.
Source and usage guidance: https://developers.google.com/identity/branding-guidelines.

It identifies Google authentication only; it is not a Lunowa brand mark.
